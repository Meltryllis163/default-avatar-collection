## 默认头像收藏

很多网站和 APP 都不提供恢复默认头像的功能，导致我想把账户重新设置回默认头像时，只能从网上搜索对应的默认头像图片再上传，非常不方便。

这个需求应该非常小众，但是我相信不止我一个人有这种情况。本仓库用于存档我搜索到的默认头像图片，方便大家使用，也欢迎其他人 PR。

### PR
所有的 PR 希望能遵循以下规则：

1. 无论默认头像数量多少，都单独设置一个文件夹，文件夹名称为网站或 APP 的名称，此处优先使用原名而不是英文名。

2. 图片遵循此命名规则：`网站英文名_图片分辨率_其他信息.扩展名`。

   例如：`weibo_180x180_female.gif`。

   一般来说，头像都是正方形，因此也可以简写分辨率为：`weibo_180_female.gif`。

3. 如果你有一些额外信息需要说明，比如图片的 URL 出处、图片分类规则等等，可以在文件夹下新建一个 `README.md` 来保存。

可以参考我的[微博](./微博/)文件夹。
